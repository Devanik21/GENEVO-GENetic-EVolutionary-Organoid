# Glossary of Terms

**Genotype**: The compact specification of a neural network architecture. Contains genes that encode modular structures and connectivity.

**Phenotype**: The actual runnable/instantiated version of the neural network built from the genotype.

**ARC Benchmark**: Abstraction and Reasoning Corpus. A visual reasoning benchmark used to evaluate AGI capabilities.

**HLE**: Humanity's Last Exam. A benchmark testing general knowledge and problem-solving abilities.

**Plasticity**: The ability of local neural components to update their weights/parameters without strict reliance on global backpropagation. Example: Hebbian learning.

**Neuroevolution**: The application of evolutionary algorithms (selection, crossover, mutation) to generate and optimize artificial neural networks.
